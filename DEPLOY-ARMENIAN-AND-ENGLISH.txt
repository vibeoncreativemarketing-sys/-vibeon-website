# VIBEON CREATIVE — Free deployment guide

This project is a Next.js app and requires a PostgreSQL database for order/contact functionality.

## Recommended free deployment
- App hosting: Vercel
- PostgreSQL: Neon (free tier, subject to provider limits)

## Steps
1. Create a GitHub account if needed and create a new repository.
2. Upload/extract these project files into the repository (the contents of this folder, not the outer ZIP).
3. Create a PostgreSQL project at Neon and copy its connection string.
4. In the project directory, set `DATABASE_URL` to that connection string, then run:
   `npm install`
   `npm run db:push`
   This creates/updates the tables from `src/db/schema.ts`.
5. Import the GitHub repository into Vercel.
6. In Vercel project Settings → Environment Variables, add:
   `DATABASE_URL` = the same Neon connection string.
7. Deploy. If you change environment variables, redeploy.
8. Open the generated `.vercel.app` URL and test the contact form and checkout flow.

## Important
- Do not publish database credentials in source code or commit a `.env` file.
- The `.vercel.app` URL is free; a custom domain is optional and may cost money.
- Provider free tiers and their limits can change.
